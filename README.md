Entry for the [make.fun bounty "Warning Label for Humans: One Line, Big Laugh"](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): a single-line safety warning label that should come printed on every human being, at most 160 characters.

## The line

> CAUTION: Do not shake. Contents settle emotionally, leak from the eyes if tilted, and may explode if asked 'are you okay?' twice.

129 characters. Written like a real printed label — "Do not shake", "Contents..." — with the laugh landing in the last few words, and the joke is pure recognition: the human who insists it is fine while visibly falling apart.

## How it works

`main.py` (Python 3, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to an `output/` directory next to the script when the variable is unset.
